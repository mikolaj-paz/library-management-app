2. TEST-ONLY CONFIGURATION / INFRASTRUCTURE
================================================================================

architecture-tests/pom.xml
  - Depends on shared-kernel plus catalog, lending, and users domain/application
    modules so ArchUnit can inspect those production classes from tests.

catalog-infrastructure/pom.xml and lending-infrastructure/pom.xml
  - Provide test dependencies used by controller and JDBC tests.

users-infrastructure/pom.xml
  - Adds sqlite-jdbc with test scope for JdbcReaderAccountRepositoryTest.

TEST HELPERS
  - catalog/.../SqliteTestDatabase.java aligns in-memory SQLite schema with tests.
  - lending/.../SqliteTestDatabase.java aligns in-memory SQLite schema with tests.

BOOTSTRAP TEST CONFIG
  - bootstrap/src/test/resources/application.properties
  - Uses a random SQLite file per test context:
      jdbc:sqlite:target/library-acceptance-test-${random.uuid}.db
    This avoids stale Flyway schema history/checksum issues between repeated
    test runs. It is test-only configuration.

No production Java code or production migration changes are required for this
test update. Existing production bugs are documented with temporarily disabled
tests instead of being fixed here.

5. HOW TO RUN TESTS
================================================================================

ALL TESTS:
  .\mvnw.cmd test

CLEAN FULL VERIFICATION:
  .\mvnw.cmd clean test

TESTS + FORMAT + LINT (CI):
  .\mvnw.cmd verify

INSTALL (build + test + local .m2):
  .\mvnw.cmd install

Avoid "clean install" if OneDrive locks target\ folder.

SINGLE TEST CLASS (nested modules need ":" prefix):
  .\mvnw.cmd -pl :catalog-domain -Dtest=BookTest test
  .\mvnw.cmd -pl :catalog-application -Dtest=AddBookCopyServiceTest test
  .\mvnw.cmd -pl :catalog-infrastructure -Dtest=JdbcCatalogQueryPortTest test
  .\mvnw.cmd -pl :lending-domain -Dtest=BookCopyTest test
  .\mvnw.cmd -pl :lending-application -Dtest=LendBookCopyServiceTest test
  .\mvnw.cmd -pl :lending-infrastructure -Dtest=LoanControllerTest test
  .\mvnw.cmd -pl :notifications-application -Dtest=InformServiceTest test
  .\mvnw.cmd -pl :users-application -Dtest=RegisteringReaderAccountTest test
  .\mvnw.cmd -pl :architecture-tests -Dtest=HexagonalArchitectureTest test
  .\mvnw.cmd -pl bootstrap -Dtest=LendingAcceptanceTest test

CONFIRM TESTS RAN:
  Output must contain:
    [INFO]  T E S T S
    [INFO] Running com.example.library....
    [INFO] Tests run: X, Failures: 0, Errors: 0, Skipped: Y

  BUILD SUCCESS in <1s without T E S T S = wrong module, no tests executed.
