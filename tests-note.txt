4. HOW TO RUN TESTS
================================================================================

ALL TESTS:
  .\mvnw.cmd test

TESTS + FORMAT + LINT (CI):
  .\mvnw.cmd verify

INSTALL (build + test + local .m2):
  .\mvnw.cmd install

Avoid "clean install" if OneDrive locks target\ folder.

SINGLE TEST CLASS (nested modules need ":" prefix):
  .\mvnw.cmd -pl :catalog-application -Dtest=AddBookCopyServiceTest test
  .\mvnw.cmd -pl :lending-domain -Dtest=BookCopyTest test
  .\mvnw.cmd -pl :lending-application -Dtest=LendBookCopyServiceTest test
  .\mvnw.cmd -pl :lending-infrastructure -Dtest=LoanControllerTest test
  .\mvnw.cmd -pl :catalog-infrastructure -Dtest=JdbcCatalogQueryPortTest test
  .\mvnw.cmd -pl :architecture-tests -Dtest=HexagonalArchitectureTest test
  .\mvnw.cmd -pl bootstrap -Dtest=LendingAcceptanceTest test

CONFIRM TESTS RAN:
  Output must contain:
    [INFO]  T E S T S
    [INFO] Running com.example.library....
    [INFO] Tests run: X, Failures: 0, Errors: 0, Skipped: Y

  BUILD SUCCESS in <1s without T E S T S = wrong module, no tests executed.
